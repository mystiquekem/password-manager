\chapter{Introduction}
\label{ch:intro}

In this report, we present the design and implementation of a secure password manager. The system is built from the ground up, with a heavy focus on implementing and managing cryptographic primitives manually to demonstrate a deep understanding of cryptographic flows.

\section{Project Objectives}
\begin{itemize}
    \item Implement core cryptographic algorithms (AES-128, HMAC-SHA256, PBKDF2).
    \item Design a secure file-based storage system for credentials.
    \item Achieve "Encrypt-then-MAC" authentication to ensure data integrity and authenticity.
    \item Provide a graphical user interface (GUI) for easy vault management.
\end{itemize}
