\chapter{Conclusion}
\label{ch:conclusion}

The development of this password manager has demonstrated the successful integration of modern cryptographic primitives into a functional application. By manually implementing the pipeline and constructing a custom vault file format, we have achieved a high degree of transparency and security control.

\section{Summary of Achievements}
\begin{itemize}
    \item Full implementation of Encrypt-then-MAC using AES and HMAC.
    \item Modular code structure following industry best practices.
    \item Comprehensive visual documentation of cryptographic flows.
\end{itemize}

\section{Future Work}
Future enhancements could include multi-factor authentication, cloud synchronization with end-to-end encryption, and hardware security module (HSM) support for key storage.
